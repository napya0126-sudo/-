# ボイスメモ → ワンタップ文字起こし & AI要約 アイデアメモ

iPhone のボイスレコーダー(ボイスメモ)で録音した音声を、**ワンタップで文字起こしして AI が要約する**仕組みのアイデア集。手軽さ順に 3 案 + 差別化ポイントをまとめる。

---

## 案 A:ショートカット + API(ノーコード、最速で今日から使える)

**コンセプト:** アプリを作らず、iOS「ショートカット」アプリだけで実現する。

### フロー
1. ボイスメモで録音 → 共有シートから「文字起こし&要約」ショートカットをタップ(ここがワンタップ)
2. ショートカットが音声ファイルを文字起こし API(OpenAI Whisper API など)に POST
3. 返ってきたテキストを Claude API に渡し、「要点 3 行 + 決定事項 + TODO」の形式で要約
4. 結果をメモアプリ / Notion / Google Drive に自動保存し、通知で表示

### ポイント
- 開発ゼロ。ショートカットの「URL の内容を取得」アクションで API を直接叩ける
- アクションボタン(iPhone 15 Pro 以降)に「録音開始→終了時に自動で文字起こし」を割り当てれば、録音から要約まで完全ワンタップ化できる
- コスト目安:Whisper API 約 $0.006/分 + Claude Haiku の要約でほぼ無視できる金額。1 時間の会議でも 40 円前後

### 弱点
- 長時間録音(25MB 超)はファイル分割が必要
- オフラインでは動かない

---

## 案 B:ネイティブ iOS アプリ(共有拡張 + オンデバイス処理)

**コンセプト:** ボイスメモの共有シートに現れる Share Extension を持つ専用アプリ。プライバシー重視でオンデバイス文字起こし。

### 技術構成
| レイヤー | 技術 |
|---|---|
| 文字起こし | WhisperKit(オンデバイス Whisper、ネット不要)or iOS 標準の `SFSpeechRecognizer` |
| 要約 | Claude API(`claude-haiku` で高速・低コスト)。オフライン時はキューに積んで後で処理 |
| 取り込み | Share Extension(ボイスメモから共有)+ アプリ内録音ボタン |
| 保存 | SwiftData + iCloud 同期。Markdown エクスポート対応 |

### UX
- 録音一覧に「要約済み / 未処理」バッジ
- 要約フォーマットをテンプレート化:会議モード(決定事項・宿題)、日記モード(感情・出来事)、アイデアモード(箇条書き展開)
- 話者分離(diarization)を入れると会議録として一気に実用的になる

### 弱点
- 開発コストが高い(App Store 審査・課金設計も必要)
- iOS 18 以降はボイスメモ自体に文字起こし + Apple Intelligence 要約が載ったため、**「標準機能との差別化」が必須**(→ 下記参照)

---

## 案 C:ショートカット + 自前バックエンド(Supabase Edge Functions)

**コンセプト:** 案 A の手軽さと案 B の拡張性の中間。入口はショートカット、処理はサーバー側。

### フロー
1. ショートカットが音声を Supabase Storage にアップロード
2. Edge Function が発火:文字起こし → Claude で要約 → DB に保存
3. 完了したらプッシュ通知(またはショートカットがポーリングして結果表示)
4. Web ダッシュボードで過去の録音を全文検索・タグ管理

### ポイント
- 長時間音声もサーバー側で分割処理できる(案 A の弱点を解消)
- 蓄積したテキストに対して「今週の会議の決定事項を横断検索」のような RAG 的な使い方に発展できる
- 家族・チームで共有ワークスペース化も可能

---

## iOS 標準機能に勝つための差別化ポイント

iOS 18+ のボイスメモは文字起こしを標準搭載しているので、単なる「文字起こしアプリ」では価値が薄い。勝ち筋は:

1. **出力先との統合** — 要約を Notion / Slack / Google Docs / カレンダー(次回アクションを予定化)へ自動ルーティング
2. **フォーマットの深さ** — 議事録テンプレ、SOAP 形式(医療)、商談メモ(BANT)、日報など職種別テンプレート
3. **蓄積と検索** — 録音が溜まるほど価値が出る「自分の音声ナレッジベース」。「先月○○さんと話した件」を自然文検索
4. **アクション抽出** — 要約だけでなく TODO を抽出してリマインダー登録まで自動化
5. **多言語** — 日英混在の会議の文字起こし + 日本語要約は標準機能が弱い領域

## おすすめの進め方(MVP ロードマップ)

1. **Week 1:** 案 A のショートカットを自分用に作り、毎日使って要約プロンプトを磨く(ここが一番価値の源泉)
2. **Week 2–3:** 案 C に移行。Supabase + Edge Function で保存・検索を追加
3. **その後:** 使用データから刺さるテンプレートが見えたら、案 B のネイティブアプリ化 or Web アプリとして公開を判断

まず「自分が毎日使うか」を案 A で 1 週間検証するのが最小リスク。
